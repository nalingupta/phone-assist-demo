# Insurance rejection codes

<!-- Mock demo policy, not real Walgreens policy. -->

- Code 70, product not covered: offer the covered alternative or a cash price.
- Code 75, prior authorization required: the prescriber must submit the authorization; typical turnaround is 2 to 3 business days.
- Code 76, plan limit exceeded: the quantity or days' supply is above the plan limit; offer the covered quantity.
- Code 79, refill too soon: a timing rejection, not a coverage problem; give the eligible date.
- Code 88, drug utilization review: a safety flag that the pharmacist must review before the claim can be rerun.

Always read the rejection reason back to the caller in plain words before rerunning a claim.
