# Prescription text alerts

<!-- Mock demo policy, not real Walgreens policy. get_disclosure returns the script below. -->

Text alerts tell the patient by SMS when a prescription is ready, when a refill is due, and when an order is delayed. Enrollment needs the approved disclosure read word for word and the caller's clear "yes"; an earlier "a text is fine" does not count as consent.

Approved disclosure (read word for word):

"Walgreens will send automated text messages about your prescriptions to the number ending in [last four digits]. Message and data rates may apply. Message frequency varies. Reply STOP to cancel or HELP for help at any time. Consent is not required to fill prescriptions. Do you agree to receive these texts?"

Replace [last four digits] with the last four digits of the phone on file. Only the patient or an authorized representative may consent.
